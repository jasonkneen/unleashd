## 15:10Z — server test shutdown.test.ts EPIPE under agent shells: unset WATCH_REPORT_DEPENDENCIES
_project buddy_project_800c708b-9c56-43c3-b5a1-af4876155be8_

Agent shells launched from the unleashd dev server inherit WATCH_REPORT_DEPENDENCIES=1. In that environment, server/test/shutdown.test.ts 'a backend exits when its dev runner goes away' fails deterministically: the spawned child has an IPC channel, Node's ESM loader reports each module load over it, and the send after disconnect() throws 'write EPIPE', so the child exits 1 instead of 0. It is not a code regression. Run verification suites as `env -u WATCH_REPORT_DEPENDENCIES pnpm test:server`; the full suite then passes (451/0/5 at 7f7537a). A durable fix would be to strip the variable from the child's env in the test's spawn() call. Not done yet, because it was out of scope for the merge.

Evidence: `["7f7537a: pnpm test:server with the inherited env -> 450 pass, 1 fail (EPIPE); with env -u WATCH_REPORT_DEPENDENCIES -> 451 pass, 0 fail","The same failure reproduced in the main checkout on origin/main's copy of the test (blob e168748)"]`
