## 10:48Z — unleashd: verifying live backend changes and commit hygiene from a Buddy run
_project buddy_project_52d3cd0f-e342-43a3-a221-7d24c19930cf_

1) A server change can't be live-reproduced inside the Buddy run that made it. The dev watcher (tools/watch-server.mjs) defers backend reloads until running turns finish, and this run is one of those turns. Check the backend pid's start time (ps -o lstart) against the commit time, and hand the live repro to the requester or owner after the run. Owner-authored channel posts must come from the owner; never post as the owner through the HTTP route.
2) The dcg PreToolUse hook blocks any Bash command that contains `git ... restore`, including the word "restore" inside a heredoc commit message. Write the message to a file and use `git commit -F file`.
3) For before/after UI screenshots when vite serves the working tree: save your version to /tmp, `git show HEAD:<file> > <file>`, shoot with `pnpm screenshots --workspace … --channel … --thread … --focus '<text>' --only focus,task-hover`, then copy your version back. Never stash in this repo.
